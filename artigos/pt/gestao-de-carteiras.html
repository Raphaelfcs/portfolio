Gestão de carteiras de beneficiários

Serviços em EKS, notificações em Lambda e integração privada com o data lake.

Raphael Santos3 min de leitura
Em resumo

EKS e Lambda no mesmo produto: cada um onde faz sentido.

01O problema

API de gestão de carteiras com partes contínuas e partes por evento.

02A solução

O núcleo da API em EKS, tarefas por evento em Lambda e backup do banco com plano dedicado.

Gestão de carteiras de beneficiários

  1. Portal e app pelo CloudFront.
  2. APIs no API Gateway.
  3. Serviços de vínculo e tipificação no EKS.
  4. Dados no RDS com backup.
  5. Lambda envia notificações.
  6. Integração com o data lake por rede privada.

O código

module "kms_key" {
  source = "git::https://github.com/Raphaelfcs/automacao_terraform.git//aws/kms-key"

  name_prefix             = local.name_prefix
  deletion_window_in_days = 7

  source = "git::https://github.com/Raphaelfcs/automacao_terraform.git//aws/vpc"

  name_prefix        = local.name_prefix
  cidr_block         = "10.20.0.0/16"
  azs                = ["sa-east-1a", "sa-east-1b"]
  single_nat_gateway = true
  eks_cluster_name   = "demo-dev"
  tags               = local.tags
}

03Discussão

Módulos Terraform usados:

  • aws/kms-key Chave KMS (CMK) da plataforma
  • aws/vpc VPC em três camadas
  • aws/eks-cluster Cluster EKS privado
  • aws/rds-instance RDS MySQL/PostgreSQL privado
  • aws/lambda-function Função Lambda empacotada
  • aws/backup-plan AWS Backup centralizado

FinOps: onde está o custo

ComponenteO que pesaAlavanca
aws/eks-clusternós do EKS (EC2) e o control plane por clusterautoscaling de nós (Karpenter/Cluster Autoscaler), Spot para cargas tolerantes e Savings Plans para a base
aws/rds-instanceclasse da instância e Multi-AZ do RDSdimensionar pela métrica real, reserva para PRD e parar HML/DEV fora do horário
aws/vpcNAT Gateway por AZ e tráfego que passa por eleum NAT só em DEV e VPC endpoints para S3/ECR tirarem tráfego do NAT

No repositório, aws/tag-compliance, aws/finops-cost-report, aws/cur-focus-export e aws/instance-scheduler fecham o ciclo: tags obrigatórias, relatório de custo, export CUR/FOCUS e agenda de desligamento.
